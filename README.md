# 字卡传讯

一个可以直接在浏览器里打开的"梦角"聊天小屋。梦角的回复来自你自己写的字卡回复库，说什么、怎么说，都由你决定。数据默认保存在你自己的浏览器里，也可以接入云端，换设备时一键恢复。

## 聊天

- **字卡回复**：自己编写回复库，支持分组管理，批量导入、编辑、删除。
- **梦角状态与拍一拍**：状态文案、拍一拍文案都可以自定义。
- **多种消息**：文字、图片、表情包、语音消息、引用回复、撤回、收藏。
- **已读回执 / 正在输入**：节奏贴近真实聊天，回复的快慢可以在设置里调。
- **批量发送**：一次发多条，不用一条条点。
- **让 ta 主动**：不想等的时候，让梦角主动来找你。
- **新消息横条**：你在别的页面时，梦角发来新消息会在顶部提示，点一下就回到聊天。

## 更多功能（输入框旁的"+"）

- **红包**：给梦角发红包，写祝福语；梦角也会发红包给你，有完整的收发记录。
- **搞怪**：朝梦角的头像扔番茄、鸡蛋、蛋糕，或者直接泼一桶水，全是手绘动画。梦角也可能朝你扔回来。聊天里会留下一条记录，比如"我 向 梦角 扔了 番茄"。
- **视频通话**：通话窗口可以拖动、缩放，换通话背景，通话记录会留在聊天里。
- **语音**：支持语音消息，也可以配置语音合成，让梦角开口说话。
- **图片**：发送图片和视频。

## 情侣空间

- **动态**：发动态、评论、点赞，像朋友圈一样。
- **相册**：自动收集动态里的图片，支持收藏和回收站。
- **心情手账**：用日历记录每天的心情，支持自定义心情。
- **纪念日**：相遇天数、倒数日、自定义纪念日，可以设置封面。
- **电影院**：约好一起看，进入沉浸观影，边看边聊。

## 陪伴

- 学习、工作、运动、睡眠四种陪伴模式，梦角会陪着你，也会来邀请你。
- 陪伴日记记录每一次陪伴，可以写备注。
- 背景音、白噪音，可以自己添加歌单。

## 高级功能

- **经期记录**：日历标记、症状和流量记录、周期统计与提醒。
- **问卷**：你可以问梦角，梦角也可以问你，有历史记录和回收站。
- **信箱**：给梦角写信、收信。
- **占卜小游戏**：塔罗占卜、随机抽签、抛硬币。
- **统计与词云**：聊天统计、收藏夹、聊天搜索、词云。
- **悬浮音乐播放器**：可以自己添加歌单

## 个性化

- 自定义主题、主题方案、聊天背景、气泡样式。
- 头像、头像框、头像形状，你和梦角可以分开设置。
- 表情包库：梦角的表情库和你自己的表情库分开管理。

## 数据与同步

- **本地保存**：聊天记录、回复库、设置都保存在你的浏览器里。
- **云端同步**：接入自己的云存储后，数据和图片会自动同步，换设备或清理浏览器后可以从云端恢复梦角。
- **备份与导入**：可以按需选择内容导出备份，需要时再导入。

## 使用小提示

- 第一次使用，先去回复库添加一些字卡，梦角才有话说。
- 想要换设备或防止数据丢失，建议接入云端，或者定期导出备份。
- 清理浏览器数据会清掉本地内容，操作前请先备份。
